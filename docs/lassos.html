BUCHILAB / ACTION-LEVEL LASSOS Fixed points Method

Show the path.
Repeat the failure.

A reachable bad component explains that a policy fails. An action-labelled prefix and a closed non-goal cycle show exactly how. Follow the prefix once; repeat the cycle forever.

Each witness defeats one fixed positional controller policy. It is not one environment strategy defeating all controller choices.

1. Choose the finite game

2. Fix the controller policy

Anchor is the first input-ordered reachable cyclic non-goal vertex. Prefix and cycle are individually shortest for that anchor, with retained input-action order breaking ties. This need not be the globally shortest lasso.

3. Follow the prefix once

4. Repeat the non-goal cycle

Every step names its owner and exact action. Controller edges must match the chosen policy; environment choices are a possible adversarial behavior, not a fairness assumption. Goals may occur on the finite prefix, never on the repeated cycle.

5. Audit independently

The native generator uses BFS predecessor paths and the original SCC audit. The separate checker enumerates bounded simple walks and independently classifies every joint positional-policy lasso. The browser enumerates simple walks too. Exact types, action provenance, ordering and every winning/null witness are checked. Shared model validation, not formal proof.
